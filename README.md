# Airline Reservation System

A simple full-stack Airline Reservation System built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Features

- User Registration and Login
- JWT Authentication
- Search Flights
- View Available Flights
- Book Flights
- View My Bookings
- Cancel Bookings
- Automatic Seat Management
- User-specific Bookings

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
